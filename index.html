TdeZip-Tools Repository

Official APT repository for high-performance companion archive and compression utilities for TdeZip (TDE Archive Manager).

🚀 APT Repository Setup

To enable automatic installation and updates of companion archiving tools via APT:

echo "deb [trusted=yes] https://seb3773.github.io/tdezip-tools/ stable main" | sudo tee /etc/apt/sources.list.d/tdezip-tools.list
sudo apt-get update

📦 Available & Upcoming Packages

lha Available

Version 1.14i (native C, 96 KB, zero Java). Full archive creation (-a), updating (-u), and extraction (-x).

sudo apt install lha

pea In Development

Complete pure C rewrite of the PEA engine, ultra-lightweight and fast, replacing the legacy Pascal binary.

uharc In Development

Native C UHARC 0.6b engine re-implemented via European interoperability reverse-engineering (ALZ compression & extraction).

🔍 Source Code & Reproducible Builds

All packaged tools include their full C source code in this repository. To rebuild any package locally from source:

git clone https://github.com/seb3773/tdezip-tools.git
cd tdezip-tools/lha
./build_deb.sh
