TdeZip-Tools Repository

Dépôt APT officiel des outils et moteurs d'archivage haute performance pour TdeZip / PeaZip.

🚀 Configuration du Dépôt APT

Pour permettre à TdeZip (ou APT) d'installer et mettre à jour automatiquement les outils auxiliaires :

echo "deb [trusted=yes] https://seb3773.github.io/tdezip-tools/ stable main" | sudo tee /etc/apt/sources.list.d/tdezip-tools.list
sudo apt-get update

📦 Paquets Disponibles & En Développement

lha Disponible

Version 1.14i (C natif, 96 Ko, 0 Java). Supporte la compression/création d'archives (-a), la mise à jour (-u) et l'extraction (-x).

sudo apt install lha

pea En cours

Portage complet du moteur PEA en C pur, ultra-léger et haute performance, en remplacement du binaire Pascal historique.

uharc En cours

Moteur UHARC 0.6b réimplémenté en C natif par rétro-ingénierie légale (compression et décompression ALZ).

🔍 Transparence et Compilation depuis les Sources

Toutes les sources C des outils packagés sont incluses dans ce dépôt. Pour recompiler localement n'importe quel paquet :

git clone https://github.com/seb3773/tdezip-tools.git
cd tdezip-tools/lha
./build_deb.sh
